# Morrowframe Dispatch — desktop app

**Download:** [Latest release](https://github.com/ashtongreer121-bit/morrowframe-dispatch-releases/releases/latest)

| Computer | File to download |
|---|---|
| Mac (Apple Silicon or Intel) | `Morrowframe.Dispatch_x.y.z_universal.dmg` |
| Windows | `Morrowframe.Dispatch_x.y.z_x64-setup.exe` |

After the first install the app updates itself.

## Installing

**Mac:** open the `.dmg` and drag Morrowframe Dispatch into Applications, then open it.
If macOS says it can't verify the developer, go to **System Settings → Privacy & Security**,
scroll down, click **Open Anyway**, and confirm. You only need to do this once.

**Windows:** run the `-setup.exe`. If you see "Windows protected your PC", click
**More info → Run anyway**. No admin rights are needed.

This repository only holds release files. The app's source code is private.
